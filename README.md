# 🧠Deep Learning

A structured collection of **Deep Learning concepts, implementations, experiments, and practical notebooks** documenting my journey from fundamental neural networks to modern Transformer architectures.

This repository focuses on understanding **how deep learning models work internally**, combining mathematical intuition with practical implementations using Python, NumPy, TensorFlow, and Keras.

---

## 📚 What This Repository Covers

The repository follows a progressive learning path, starting from the fundamentals of neural networks and gradually moving toward advanced architectures used in Computer Vision and Natural Language Processing.

### 1. 🧩 Artificial Neural Networks (ANN)

Fundamentals of neural networks and how they learn from data.

Topics include:

- Perceptron
- Artificial Neural Networks
- Forward Propagation
- Backpropagation
- Loss Functions
- Activation Functions
- Gradient Descent
- Batch Gradient Descent
- Stochastic Gradient Descent
- Mini-Batch Gradient Descent
- Optimizers
- Vanishing Gradient Problem
- Dropout
- Batch Normalization
- Universal Approximation Theorem

---

### 2. 🖼️ Convolutional Neural Networks (CNN)

Understanding how neural networks process and learn visual features from images.

Topics include:

- Convolution Operation
- Filters and Kernels
- Stride
- Padding
- Feature Maps
- Pooling
- Max Pooling
- CNN Architecture
- Transfer Learning
- Pretrained Models
- ResNet50
- VGG16
- CNN Visualization

Practical implementations are included to understand how convolutional networks learn hierarchical visual representations.

---

### 3. 🔄 Recurrent Neural Networks (RNN)

Sequence modeling and the fundamentals of processing sequential data.

Topics include:

- Simple RNN
- Recurrent Neural Network Architecture
- Sequence Modeling
- Many-to-One Architecture
- Many-to-Many Architecture
- Bidirectional RNN
- Deep RNN
- Sentiment Analysis

---

### 4. 🧠 LSTM & GRU

Exploring gated recurrent architectures designed to handle long-term dependencies in sequential data.

Topics include:

- Long Short-Term Memory (LSTM)
- LSTM Cell
- Forget Gate
- Input Gate
- Output Gate
- Cell State
- Gated Recurrent Unit (GRU)
- Update Gate
- Reset Gate
- Deep LSTM
- Deep GRU

These architectures demonstrate how recurrent models address limitations associated with learning long-term dependencies.

---

### 5. 👁️ Attention Mechanism

Understanding the foundation behind modern Transformer architectures.

Topics include:

- Attention Mechanism
- Query, Key and Value
- Scaled Dot-Product Attention
- Self-Attention
- Contextual Representations
- Multi-Head Attention

Attention allows a model to dynamically focus on different parts of a sequence when producing representations. Modern Transformer architectures build heavily on these ideas.

---

### 6. 🤖 Transformers

A detailed exploration of the Transformer architecture and its components.

Topics include:

- Transformer Architecture
- Encoder
- Decoder
- Self-Attention
- Multi-Head Attention
- Positional Encoding
- Masked Self-Attention
- Cross-Attention
- Feed-Forward Networks
- Residual Connections
- Layer Normalization
- Encoder-Decoder Architecture

The Transformer architecture introduced an attention-based approach that enables highly parallel sequence processing and became a foundation for many modern NLP models.
